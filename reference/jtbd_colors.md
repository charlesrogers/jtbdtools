# JTBD color palette

Returns a named color palette for JTBD opportunity classifications.

## Usage

``` r
jtbd_colors()
```

## Value

A named character vector of colors

## Examples

``` r
jtbd_colors()
#>      underserved    appropriately       overserved high_opportunity 
#>        "#E74C3C"        "#95A5A6"        "#3498DB"        "#E74C3C" 
#>  low_opportunity       importance     satisfaction      opportunity 
#>        "#2ECC71"        "#2C3E50"        "#16A085"        "#E74C3C" 
```
