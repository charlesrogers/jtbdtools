# jtbdtools: Quantitative Jobs-to-Be-Done Analysis Using Outcome-Driven Innovation

Implements Ulwick's Outcome-Driven Innovation opportunity scoring
formula. Calculates importance, satisfaction, and opportunity scores
from Likert-scale survey data. Provides ggplot2 visualizations and gt
tables for segment comparison and opportunity identification.
