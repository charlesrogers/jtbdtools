# Remove JTBD text formatting

Cleans up objective names for display: removes common prefixes like
"minimize_time_to\_" and replaces underscores with spaces.

## Usage

``` r
remove_weird_text_formatting.jtbd(your_data_frame)
```

## Arguments

- your_data_frame:

  A data frame with objective text columns

## Value

A data frame with cleaned text
