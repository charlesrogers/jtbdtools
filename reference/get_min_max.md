# Get min and max values for JTBD scores

Get min and max values for JTBD scores

## Usage

``` r
get_min_max(your_long_data_frame, job_steps = NULL)
```

## Arguments

- your_long_data_frame:

  A long format data frame

- job_steps:

  Character vector of job steps to filter (default: all)

## Value

A data frame with min, max, and difference calculations
